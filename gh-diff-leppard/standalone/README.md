# gh-diff-leppard 🐆

`gh` extension for [Diff Leppard](https://github.com/georgestephanis/diff-leppard): AI code review of pull requests and local changes with **your own** LLM server (vLLM, Ollama, LM Studio, llama.cpp, any OpenAI-compatible API).

```bash
gh extension install georgestephanis/gh-diff-leppard

gh diff-leppard test           # check your model server
gh diff-leppard                # review the PR for the current branch
gh diff-leppard 123 --draft    # review PR #123 and leave a pending review for you to edit
gh diff-leppard local          # review uncommitted changes
```

It runs `diff-leppard` from your PATH if you have it installed, and otherwise `npx diff-leppard@__VERSION__` (Node.js 20+). Configure it in `~/.config/diff-leppard/config.json`. See the [main README](https://github.com/georgestephanis/diff-leppard#readme).

This repository is generated by the main repo's release workflow. Please send issues and pull requests to [georgestephanis/diff-leppard](https://github.com/georgestephanis/diff-leppard).
